RobloxWeb Studio

L'editor desktop per costruire i tuoi giochi: piazza parti, usa gli strumenti dell'editor, premi Testa per provare il livello e Pubblica per creare un nuovo gioco o una nuova versione sul server.

Scarica Studio

Scarica per Windows Scarica per Linux

Windows e Linux · zip · x86_64.

Se il download restituisce 404, i binari non sono ancora stati compilati: dalla root del repository esegui ./build_studio.sh.

Requisiti

  • Windows 10 o successivo, oppure Linux x86_64.
  • Godot non è richiesto: Studio è distribuito come pacchetto autonomo.
  • Per pubblicare serve un server RobloxWeb attivo e un account non ospite.

Comandi

Linux: unzip RobloxWebStudio-linux.zip && chmod +x RobloxWebStudio.x86_64, poi avvia il file.

Windows: estrai lo zip e apri RobloxWebStudio.exe.

Come pubblicare

  1. Avvia Studio e accedi con il tuo account (o continua offline).
  2. Crea un nuovo livello, apri un file o scegli uno dei tuoi giochi.
  3. Apri Script per aggiungere codice Lua alla parte selezionata; Output mostra print, avvisi ed errori.
  4. Premi Simula per eseguire anche gli script nell'editor, oppure Testa per giocare la versione corrente.
  5. Premi Pubblica, scegli titolo, descrizione e visibilità.
  6. La thumbnail viene catturata dalla vista corrente dell'editor.
  7. La pagina del gioco mostra subito la nuova versione.

Server locale

python3 server/run.py
URL predefinito in Studio: http://127.0.0.1:9080.
