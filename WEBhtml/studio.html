RobloxWeb Studio

L'editor desktop per costruire i tuoi giochi: piazza parti, usa gli strumenti dell'editor, premi Testa per provare il livello e Pubblica per creare un nuovo gioco o una nuova versione sul server.

Scarica per Windows Scarica per Linux

Windows e Linux x86_64 · zip. Se il download restituisce 404, i binari non sono ancora stati compilati: dalla root del repository esegui ./build_studio.sh.

Linux: unzip RobloxWebStudio-linux.zip && chmod +x RobloxWebStudio.x86_64 poi avvia il file. Windows: estrai lo zip e apri RobloxWebStudio.exe. Il server deve essere attivo su http://127.0.0.1:9080 (o cambia l'URL nella schermata iniziale).

Come pubblicare

  • Avvia Studio e accedi con il tuo account (o continua offline).
  • Crea un nuovo livello, apri un file o scegli una delle tue place.
  • Apri Script per aggiungere codice Lua alla parte selezionata; Output mostra print, avvisi ed errori.
  • Premi Simula per eseguire anche gli script nell'editor, oppure Testa per giocare la versione corrente.
  • Premi Pubblica, scegli titolo, descrizione e visibilità.
  • La thumbnail viene catturata dalla vista corrente dell'editor.
  • La pagina del gioco mostra subito la nuova versione.

Server locale

python3 server/run.py
URL predefinito in Studio: http://127.0.0.1:9080.
